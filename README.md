# TENVO App — Starter Kit v2

Ce dossier contient les fichiers de l'application Tenvo placés **directement à la racine**.

## 🚀 Mise en ligne sur GitHub & Netlify

1. Extrais l'archive `tenvo-app-v2.zip`.
2. Va sur ton dépôt GitHub (`github.com/duanendpro-rgb/TENVO.APP`).
3. Clique sur **Add file** -> **Upload files**.
4. Sélectionne **tous les fichiers et dossiers** à l'intérieur du dossier extrait (`index.html`, `package.json`, dossier `src/`, dossier `sql/`, etc.).
5. Valide avec **Commit changes**.
6. Netlify va détecter le fichier `src/main.jsx` et déployer ton site sans aucune erreur !
